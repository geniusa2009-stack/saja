# SAJA — هندسة المحتوى وتجربة المستخدم (المرحلة الأولى)

## المبدأ
- **العمر** حاجز أمان مستقل، ويظل تابعًا لملف الحساب وضوابط الخادم. اختيار رحلة جديدة لا يغيره.
- **الهدف** (`exploring` / `new-muslim` / `learn-more` / `child`) اختيار شخصي، لا استنتاج لمعتقد المستخدم.
- **المستوى والاهتمامات وطريقة التعلّم** إشارات لترتيب المقترحات فقط، ولا تحجب المحتوى المناسب للعمر.
- **القصص والعالم** اختياريان في الصفحة الرئيسية. المكتبة الكاملة تحتفظ بإمكان تصفحهما.
- **التحقق الشرعي** منفصل عن الفهرسة: مادة Demo تظل Demo، والقصص الخيالية تحمل وصفها.

## المصادر التي يغطيها الفهرس مباشرة
1. المصدر الأساسي للمهمات `src/content/missions.ts`.
2. الأسئلة والمعلومات `src/content/knowledge.ts`، مع فتح صفحة البحث على السؤال.
3. الأحاديث `src/content/hadith.ts`، مع الإبقاء على المصدر وحالة المراجعة في صفحة الحديث نفسها.
4. الأنشطة المرتبطة بالأحاديث `src/content/hadithActivities.ts`.
5. الحكايات الخيالية `src/content/sideStories.ts`، مع فتح الحلقة المطلوبة مباشرة دون تغيير النص.
6. مسارات وتوصيات `src/content/learningGraph.ts`.
7. بوابات أساسية ثابتة: المصحف، القرآن، أدوات الأمانة والنور، اليوميات، العالم والرحلة.

## قابلية التوسّع
المرحلة التالية: بناء سجل نشر Server-side موحّد يجمع مواد الموظفين المعتمدة ومحتوى الخادم المتجدد في نفس الفهرس، مع البحث المفهرس والتوثيق بحسب كل نسخة منشورة. المرحلة الحالية فهرس للمواد المضمنة في التطبيق، وليس بديلاً عن نظام النشر أو مراجعة العلماء أو ضوابط الحماية.

## تجربة المستخدم
- `/home`: بداية هادئة شخصية، بدون دخول لعبة تلقائي.
- `/catalog`: مكتبة موحدة، بحث بالعربية والإنجليزية، تصفية بالقسم والنوع، عرض المزيد.
- `/profile#experience`: إعدادات التجربة، اهتمامات ومستوى، وعرض القصص/العالم/المحتوى المتقدم.
- `/`: عالم SAJA القديم كما هو للألعاب والزيارات المباشرة، ويدخله المستخدم باختياره.

## قبل الدمج
- تشغيل `npm run check` و`npm run e2e:game` على الفرع الجديد.
- مراجعة رحلة الشخص البالغ والطفل ومستخدم جديد، بالعربية والإنجليزية وعلى الموبايل.
- اختبار الاستمرار بالمعرّفات القديمة وحالات الخادم المختلفة.
- التحقق من عدم ظهور أي حالة «موثّق» بغير قرار نشر فعلي من الخادم.
